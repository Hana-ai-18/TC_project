## Quick Start

```bash
# 1. Sanity check (no data needed)
python scripts/quick_test.py

# 2. Generate regime labels (run once)
python scripts/generate_regime_labels.py --data_root TCND_vn/

# 3. Train
python -m src_track.training.trainer \
    --data_root TCND_vn/ \
    --save_dir  checkpoints/v2/ \
    --max_epochs 70

# 4. Evaluate
python scripts/run_inference.py \
    --data_root  TCND_vn/ \
    --checkpoint checkpoints/v2/best_ade.pth \
    --compute_sec
```

## Architecture

```
Data1d → PhysNorm (9d) ──┐
Data3d → SCE ViT (128d) ─┼→ Context (256d) → Regime Classifier → P(A/B/C)
Env_Data + SVE (24d) ────┘               └→ Speed Head (12 steps)
                                          └→ MoE Decoder (3 experts)
                                                    ↓
                                         72h Trajectory + Sensitivity Ellipse
```

**5 contributions:**
1. Steering Regime Framework + RII metric
2. Regime-conditioned MoE Decoder (3 experts)
3. Physics Jacobian Sensitivity Ellipse
4. SCS-specialized 72h benchmark
5. ATE/CTE root-cause → Speed Head + log-space loss

## Training Curriculum

| Phase | Epochs | Loss terms | Difficulty |
|-------|--------|------------|------------|
| 1 Warm-up | 1–15 | L_pos + L_speed | Easy only (<0.4) |
| 2 Regime | 16–30 | + L_regime | Easy+Medium (<0.7) |
| 3 Experts | 31–50 | + L_diversity | All, Regime B 1.5× |
| 4 Fine-tune | 51–70 | All (LR×0.1) | All |

**Adaptive threshold** (from v74 train script): EMA of batch median difficulty
keeps easy_frac ≈ 50% regardless of dataset distribution.
